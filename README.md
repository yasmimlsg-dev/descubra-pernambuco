# Descubra Pernambuco

Landing Page de turismo desenvolvida com HTML5 e CSS3.

## Como executar
1. Extraia a pasta `descubra-pernambuco`.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou use a extensão Live Server.

## Estrutura
- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: estilos, layout e responsividade.
- `img/`: pasta reservada para imagens locais, caso queira substituir as imagens externas.

As imagens atuais são carregadas de URLs externas e precisam de conexão com a internet.
